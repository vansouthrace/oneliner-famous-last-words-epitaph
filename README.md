A one-line tombstone epitaph of famous last words, written for the [Famous Last Words: The Funniest Epitaph](https://make.fun/bounty/u-riidzhsn-famous-last-words-the-funniest-epitaph-ff177406) bounty on make.fun.

The joke: a dying worker's last request reframes death itself as the ultimate remote-work arrangement — the grave is home, and the job can never drag him back to the office.

## The entry

> Tell my boss I'm working from home now.

## How to run

Requires Node 22.18 or later:

```sh
node main.ts
```

This writes the epitaph to `/output/entry.txt` (creating `/output` if needed) and validates that it is a single line of 1–150 characters.
